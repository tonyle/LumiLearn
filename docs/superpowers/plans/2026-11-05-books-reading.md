# Books and local read-aloud practice

Parents manage books, import PDF/photo pages or use iPad camera capture, review sentence text and normalized image regions, then publish and assign active learners. Students see assigned published books only, read original page images with sentence speakers, hear a local English device voice and tap words/sentences for Vietnamese translation. All book lists paginate and filter. Page/text mutations unpublish the book until parent review and republishing. Private uploads live under data/uploads/books.

OpenAI is authorized only for explicit parent-triggered image OCR, uses structured output/store:false and shared monthly budget accounting. Translation runs via cached Argos English-Vietnamese; short speech clips use faster-whisper tiny.en CPU int8 in an internal Docker service. Models download once using a separate internet-enabled setup container; runtime has no external network. Audio/transcripts/practice feedback remain in memory, with no database/event/browser storage. Word alignment is approximate reading feedback, not pronunciation assessment. Speech samples cap at30seconds/6MiB; shared busy gate bounds work.

Caddy adds local HTTPS3443 for the detected LAN IP with a persistent private CA. Export only the public root certificate; parent manually installs/trusts it on iPad. A private random proxy header plus exact configured HTTPS host authenticates forwarded origin. Direct HTTP3000 remains for home setup. Caddy binary file capabilities are removed at build time to retain cap_drop ALL; default_sni supports bare IP clients behind Docker NAT. Trusted TLS health check validates root and hostname.

Validation: full unit suite, parent/student access and assignment revocation integration, image and PDF import, invalid media/text-region validation, explicit review/publishing, local synthetic speech and Vietnamese translation, HTTPS certificate/hostname and parent mutation checks, browser editor/reader. Paid OCR calls are mocked in tests; real student work is never used for QA.
